# Learn C Through Practice

A beginner-friendly collection of small C programs for practicing core language concepts. Each source file is a standalone exercise that can be compiled and run independently.

## Topics

- **If-Else Statements** - conditionals, `switch`, ternary operators, and simple decisions
- **Loops** - `for`, `while`, `do-while`, number problems, series, and patterns
- **Functions** - reusable functions, combinations, permutations, HCF, and square roots
- **Pointers** - pointer basics and swapping values
- **Recursion** - recursive function examples
- **Patterms** - console pattern-printing exercises

## Getting started

You need a C compiler, such as [GCC](https://gcc.gnu.org/), installed on your computer.

Compile a program from the project root. For example:

```powershell
gcc ".\\Loops\\Factorial.c" -o factorial.exe
.\\factorial.exe
```

On macOS or Linux, use:

```bash
gcc "Loops/Factorial.c" -o factorial
./factorial
```

Replace the source file with any exercise you want to try. Most programs prompt for input in the terminal.

## Learning approach

1. Read a program and predict its output.
2. Compile and run it with several inputs.
3. Change one small part at a time to see what happens.
4. Recreate the exercise without looking at the solution.

This project is intended for learning and experimentation rather than as a production C library.
